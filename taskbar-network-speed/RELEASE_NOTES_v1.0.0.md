# Taskbar Network Speed v1.0.0

## English

Taskbar Network Speed is a lightweight native Windows taskbar utility for viewing live upload and download traffic without a floating overlay or a separate background service.

Highlights:

- compact total-speed mode and separate upload/download mode;
- daily historical traffic statistics with a local reset option;
- reliable right-click access across the whole display area;
- professional application icon embedded in the Windows executable;
- local-only history storage with no account and no telemetry.

## עברית

Taskbar Network Speed הוא כלי Win32 קל שמציג את תעבורת הרשת בשורת המשימות, ללא חלון צף וללא שירות רקע נפרד.

הגרסה כוללת מצב מהירות כוללת, מצב העלאה והורדה בנפרד, סטטיסטיקה היסטורית יומית, איפוס מקומי עם אישור, קליק ימני בכל שטח התצוגה ואייקון מקצועי המוטמע בקובץ ההפעלה.
